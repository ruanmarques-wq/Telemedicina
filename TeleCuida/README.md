# TeleCuida

Projeto inicial de Programação Orientada a Objetos em Java.

## Conceitos aplicados
- Encapsulamento com atributos privados e métodos de acesso.
- Herança: `Paciente`, `Medico` e `Administrador` herdam de `Usuario`.
- Classes abstratas: `Usuario`, `Pagamento` e `DocumentoMedico`.
- Interface: `ValidadorAssinatura`, implementada por `ValidadorSimulado`.
- Fluxo executável: processamento de pagamento Pix simulado, confirmação da consulta e assinatura simulada de receita.

## Como executar
Abra a pasta do projeto em uma IDE Java (por exemplo, IntelliJ IDEA, Eclipse ou VS Code com extensão Java) e execute:
`src/br/com/telecuida/app/Main.java`

Este é um protótipo didático: pagamento e assinatura são simulados; não utiliza dados reais de pacientes.
